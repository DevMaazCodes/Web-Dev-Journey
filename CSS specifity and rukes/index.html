Rules for styling and collisions

  1. Position-CSS treats styling from top to bottom i.e if 2 styles have the same specificity CSS will apply the one at the very bottom
  2. Specificity-CSS gives more importance to some selectors than others, the order is inline-1000>id-100>class/attribute/pseudo-class-10>element-1>universal-0, each selector has its own specificity value which I mention along with selector. We can add specificity of different selectors for complex selectors, the highest specificity one will be applied unless something is important.
  3. Origin-The browser defaut styling is overridden by the author's styling, so the origin of style matters.
  4. we can use !important to give importance to a particular declaration which will override all the others.
