There are 6 ways to represent color in CSS

  1. Color keyword eg-color:red;
  2. hex color code eg-color:#FF5713;
  3. rgb eg-color:rgb(70, 36, 36);
  4. rgba eg-color:rgba(70, 36, 36, 0.3);
  5. hsl eg-color: hsl(120, 50%, 50%);
  6. hsla eg-color: hsla(120, 50%, 50%, 0.3);
