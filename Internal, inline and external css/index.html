Ways to add CSS in HTML

Inline CSS
Inline CSS is when we add a style attribute to our element like done for h1, this is not recommended as it makes our code repetetive and difficult to change later
 
Internal CSS
Internal CSS is using a style tag under the head of our HTML website this allows us to choose a selector and make global declaration for the chosen selector/s, though it can let us do global edit of our elements, long styling for production grade website can make our HTML file very long and difficult to read for other developers. An example of internal CSS is in our introduction to CSS file.
 
External CSS
This is the most commonly used way of adding CSS in our HTML file. This works the same as internal CSS but saves us the mess caused by internal CSS as we link an external .CSS file in to out HTML, example is this file itself. This is commonly said the best practice is industry as it keeps our code clean while making our code flexible.
